# 安全设计

`SafetyFilter` 与模型解耦，按顺序检查：急停锁存、通信超时、shape、NaN/Inf、单步动作增量、
速度换算后的单周期上限、关节目标范围和可插拔 workspace hook。返回安全动作、裁剪维度数和原因。

`ActionChunkExecutor` 对 chunk 的每一步重新读取 state 和过滤动作，支持只执行前 N 步、提前停止、
dry-run、控制频率、延迟和裁剪计数。超时和急停是锁存状态；真实机器人中的 reset 必须要求操作员
确认，不能由模型自动恢复。

软件过滤不是安全认证。真实部署还必须有硬件急停、驱动器限位、力矩/碰撞阈值、工作区隔离、
工具负载配置、人工观察和故障演练。workspace hook 当前只有接口，选定机器人和坐标系后才能实现。
